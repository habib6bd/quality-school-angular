Self-hosted web fonts (subsets downloaded from Google Fonts, https://fonts.google.com):

- hind-siliguri-bengali-400.woff2, hind-siliguri-bengali-600.woff2
    Hind Siliguri, Bengali subset. Copyright 2014 The Hind Siliguri Project Authors
    (https://github.com/itfoundry/hind-siliguri). SIL Open Font License 1.1.
- inter-latin-variable.woff2
    Inter (variable, weights 400-700), Latin subset. Copyright 2020 The Inter Project Authors
    (https://github.com/rsms/inter). SIL Open Font License 1.1.

The SIL Open Font License 1.1 allows use, redistribution and embedding on websites:
https://openfontlicense.org/open-font-license-official-text/
Latin characters on Bangla pages fall back to Inter (see src/styles.css).
